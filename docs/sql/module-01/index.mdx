## <HLink href="/docs/sql/module-01/intro">1. Introduction to Databases, SQL, and MySQL</HLink>

A **database** is an organized place to store data so it can be saved, searched, and updated reliably.

A **DBMS (Database Management System)** is the software that actually stores, organizes, and lets you interact with a database. MySQL, PostgreSQL, and SQLite are all examples of a DBMS.

**SQL (Structured Query Language)** is the language used to talk to a relational database — to create tables, insert data, ask questions about it, and change it.

## <HLink href="/docs/sql/module-01/types-of-keys">3. Types of Keys</HLink>

  <THead>
    <TR>

  </THead>
  <TBody>
    <TR>
      <TD>Candidate Key</TD>
      <TD>Any column(s) that could be the primary key</TD>
      <TD><Code>id</Code>, <Code>employee_code</Code>, <Code>ssn</Code></TD>
    </TR>
    <TR>
      <TD>Primary Key</TD>
      <TD>The candidate key actually chosen</TD>
      <TD><Code>id</Code></TD>
    </TR>
    <TR>
      <TD>Alternate Key</TD>
      <TD>Candidate keys not chosen as primary</TD>
      <TD><Code>employee_code</Code>, <Code>ssn</Code></TD>
    </TR>
    <TR>
      <TD>Super Key</TD>
      <TD>Any set of columns that uniquely identifies a row, minimal or not</TD>
      <TD><Code>(id, email)</Code></TD>
    </TR>
    <TR>
      <TD>Composite Key</TD>
      <TD>A primary key made of multiple columns combined</TD>
      <TD><Code>(book_id, genre_id)</Code></TD>
    </TR>
    <TR>
      <TD>Foreign Key</TD>
      <TD>References a primary key in another table</TD>
      <TD><Code>department_id → departments.id</Code></TD>
    </TR>
    <TR>
      <TD>Unique Key</TD>
      <TD>Enforces no duplicates; multiple allowed per table</TD>
      <TD><Code>email</Code></TD>
    </TR>
    <TR>
      <TD>Surrogate Key</TD>
      <TD>System-generated, no real-world meaning</TD>
      <TD><Code>id INT AUTO_INCREMENT</Code></TD>
    </TR>
    <TR>
      <TD>Natural Key</TD>
      <TD>Made from real-world, meaningful data</TD>
      <TD><Code>ssn</Code>, <Code>email</Code></TD>
    </TR>
  </TBody>
