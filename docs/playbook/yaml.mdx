- Uses indentation (spaces)
- No tabs
- Usually <Highlight>.yaml</Highlight> or <Highlight>.yml</Highlight>

## 2. Key-Value Pair

```yaml title="first.yaml"
name: Akkal
age: 22
city: Kathmandu
```

#### Meaning
- name → <Highlight>key</Highlight>
- Akkal → <Highlight>value</Highlight>

##### Equivalent JSON:

```json
{
  "name": "Akkal",
  "age": 22,
  "city": "Kathmandu"
}
```

## 7. Nested Objects

```yaml title="nested_obj.yml"
user:
  name: Akkal
  age: 22

  address:
    country: Nepal
    city: Kathmandu
    zip: 44600
```

##### Structure:

```text
user
 ├── name
 ├── age
 └── address
      ├── country
      ├── city
      └── zip
```     

<br/>
---
<br/>

```yaml title="nested_nested_obj.yml"
company:
  name: XYZ

  department:
    name: Engineering

    manager:
      name: Akkal
      experience: 5
```

##### Structure:

```text
company
 └── name
 └── department
      └── name
      └── manager
           ├── name
           └── experience
```

## 11. Multiline Strings

#### Pipe <Highlight>|</Highlight> : preserve line breaks

```yaml title="multi_line_str.yml"
message: |
  Hello
  This is YAML
  Learning basics
```

##### Output:

<Output>
Hello
This is YAML
Learning basics
</Output>

---

#### Greater Than  <Highlight>></Highlight> : single line

```yaml title="multi_line_str.yml"
message: >
  Hello
  This becomes
  one line
```

##### Output:

<Output>
Hello This becomes one line
</Output>

## 13. Anchors and Defaults

YAML supports reusable default blocks using anchors <Highlight>&</Highlight> and aliases <Highlight>*</Highlight>.

```yaml title="anchor_default.yml"
default: &default_settings
  timeout: 30
  retries: 3

development:
  <<: *default_settings
  host: localhost

production:
  <<: *default_settings
  host: prod.server.com
```  

<br />
> <Highlight>default_settings</Highlight> is reused in both environments.

## 15. Docker Compose

### 15.1 Simple Node.js App
```yaml title="docker-compose.yml"
version: "3"

services:
  app:
    image: node:20

    container_name: my-node-app

    ports:
      - "3000:3000"

    volumes:
      - .:/app

    working_dir: /app

    comm and: npm start
```

### 15.2. Node.js + MongoDB
```yaml title="docker-compose2.yml"
version: "3"

services:
  app:
    image: node:20

    container_name: backend-app

    ports:
      - "5000:5000"

    volumes:
      - .:/app

    working_dir: /app

    command: npm run dev

    depends_on:
      - mongo

  mongo:
    image: mongo

    container_name: mongodb

    ports:
      - "27017:27017"

    volumes:
      - mongo-data:/data/db

volumes:
  mongo-data:
```

### 15.2. Node.js + PostgreSQL
```yaml title="docker-compose3.yml"
version: "3"

services:
  app:
    image: node:20

    ports:
      - "5000:5000"

    environment:
      DATABASE_URL: postgres://postgres:password@db:5432/mydb

    depends_on:
      - db

  db:
    image: postgres

    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: mydb

    ports:
      - "5432:5432"
```
