## 1. What is MongoDB Aggregation?

MongoDB aggregation is a way to process and transform data inside the database.

Think of it like a pipeline:

<Output>
Documents → Step 1 → Step 2 → Step 3 → Result
</Output>

Each step modifies, filters, groups, or reshapes the data.

MongoDB uses the Aggregation Pipeline:

```js
db.collection.aggregate([
  { stage1 },
  { stage2 },
  { stage3 }
])
```

<br />

## 2. Why Use Aggregation?

Aggregation helps you:

- Filter data
- Group documents
- Calculate totals/averages
- Join collections
- Transform fields
- Sort & paginate
- Build analytics

Similar to:
- SQL <Highlight>GROUP BY</Highlight>
- SQL <Highlight>JOIN</Highlight>
- SQL calculations

## 4. Most Important Aggregation Stages

### 4.1. <Code>$match</Code> : Filter Documents

Like SQL <Highlight>WHERE</Highlight>.

> Filter documents based on a condition.

### 4.2 <Code>$group</Code> : Group Documents

Like SQL <Highlight>GROUP</Highlight> BY.

<Highlight>$group</Highlight> is used to:
> Group documents by a common field and apply an aggregation operation to each group.

<Highlight>_id</Highlight> means:
> “Group by this field”

Not the actual MongoDB document ID.

##### 1. Count how many products are in each category.

```js
db.products.aggregate([
  {
    $group: {
      _id: "$category",
      totalProducts: {
        $sum: 1
      },
      products: {
        $push: {
          _id: "$_id",
          name: "$name",
          price: "$price"
        }
      }
    }
  }
]);
```

#### Output:
```js
[
  {
    _id: "Accessories",
    totalProducts: 2,
    products: [
      {
        _id: 104,
        name: "Boat Headphones",
        price: 2500
      },
      {
        _id: 105,
        name: "Gaming Mouse",
        price: 1800
      }
    ]
  },
  {
    _id: "Laptop",
    totalProducts: 1,
    products: [
      {
        _id: 103,

        price: 120000
      }
    ]
  },
  {
    _id: "Mobile",
```

### 4.4 <Code>$sort</Code> : Sort Documents

<Highlight>$sort</Highlight> is used to:
> Sort documents in ascending or descending order.

```js
db.products.aggregate([
  {
    $match: {
      brand: "Apple"
    }
  },
  {
    $project: {
      name: 1,
      price: 1,
      category: 1,
      brand: 1
    }
  },
  {
    $sort: {
```

## 5. Aggregation Pipeline Example

Find the total revenue generated by each category of products in the last 24 hours.

```js
db.orders.aggregate([
  {
    $match: {
      // last 24 hours
      orderDate: {
        $gt: new Date(Date.now() - 24 * 60 * 60 * 1000)
      }
    }
  },
  {
    $project: {
      products: 1
    }
  },
  {
    $unwind: "$products"
  },
  {
    $lookup: {
      from: "products",
      localField: "products.productId",
      foreignField: "_id",
    
      as: "productDetails"
    }
  },
  {
    $unwind: "$productDetails"
  },
  {
    $group: {
      _id: "$productDetails.category",
      totalRevenue: {
        $sum: {
          $multiply: ["$products.quantity", "$productDetails.price"]
        }
      }
    }
  }
]);
```

#### Output:
```js
[
  { _id: "Accessories", totalRevenue: 10400 },
  { _id: "Laptop", totalRevenue: 120000 },
  { _id: "Mobile", totalRevenue: 85000 }
];
```
